## 01. 删除最小值

### 题目

从顺序表中删除具有最小值的元素（假设唯一），并由函数返回被删元素的值。空出的位置由最后一个元素填补；若顺序表为空，则显示出错信息并退出运行。

### 思路

先记录第一个元素的值和下标，再从头遍历一次寻找真正的最小值。找到后，用最后一个元素覆盖最小值所在位置，最后把表长减一。整个过程只使用常量个额外变量。

### 代码

```cpp
bool DeleMin(Seqlist& L, int& e)
{
	if (L.length == 0)
	{
		return false; // 空表没有最小值，直接返回失败标志
	}

	e = L.data[0]; // e 既保存当前找到的最小值，也作为函数的结果返回
	int pos = 0;    // pos 指向当前最小值在数组中的下标

	for (int i = 1; i < L.length; i++)
	{
		if (L.data[i] < e)
		{
			e = L.data[i]; // 找到更小的元素，更新最小值

			pos = i; // 同时记录这个最小值的下标，最后才能准确删除它
		}
	}

	// 用最后一个元素覆盖最小值。若最小值原本就是最后一个元素，
	// 这里相当于把元素写回自身，不会影响结果。
	L.data[pos] = L.data[L.length - 1];
	L.length--; // 最后一个元素已经填入空位，顺序表长度减一
	return true;
}
```

函数返回 `false` 表示顺序表为空，原始代码由调用者根据返回值处理这种情况。

### 复杂度

时间复杂度为 `O(n)`；只使用常数额外变量，空间复杂度为 `O(1)`。

## 02. 原地逆置顺序表

### 题目

设计一个高效算法，将顺序表 `L` 的所有元素逆置，要求算法的空间复杂度为 `O(1)`。

### 思路

原思路只遍历前一半位置，每次交换当前元素与它在表中对称位置上的元素。

### 代码

```cpp
void Reverse(Seqlist& L)
{
	int temp;
	// 每次同时交换左右对称位置，因此只遍历前一半即可。
	for (int i = 0; i < L.length / 2; i++)
	{
		// 下标 i 的对称位置是 L.length - i - 1。
		// 先把左侧元素暂存起来，再完成左右交换。
		temp = L.data[i];
		L.data[i] = L.data[L.length - i - 1];
		L.data[L.length - i - 1] = temp;
	}
}
```

`i` 只需要走到 `L.length / 2` 之前，因为一次交换会同时处理首尾两个元素。

### 复杂度

每个元素最多参与一次交换，时间复杂度为 `O(n)`；空间复杂度为 `O(1)`。

## 03. 删除所有值为 x 的元素

### 题目

对长度为 `n` 的顺序表 `L`，编写一个时间复杂度为 `O(n)`、空间复杂度为 `O(1)` 的算法，删除顺序表中所有值为 `x` 的数据元素。

### 思路

使用下标 `k` 记录下一个保留元素应写入的位置，扫描原顺序表时把不等于 `x` 的元素依次写回。

### 代码

```cpp
void DelX(Seqlist& L, int x)
{
	// k 既是下一个保留元素的写入位置，也是已经保留的元素个数。
	// 由于 k 始终不会超过正在扫描的 i，写回不会破坏尚未读取的元素。
	int k = 0;
	for (int i = 0; i < L.length; i++)
	{
		if (L.data[i] != x)
		{
			L.data[k] = L.data[i]; // 不等于 x，保留并写到前面
			k++;                  // 准备写入下一个保留元素
		}

	}
	L.length = k; // k 最终就是删除后剩下的元素个数
}
```

`k` 最终等于保留下来的元素个数，因此可以直接用它更新表长。

### 复杂度

只扫描一遍顺序表，时间复杂度为 `O(n)`；空间复杂度为 `O(1)`。

## 04. 删除闭区间 [s, t] 内的元素

### 题目

从顺序表中删除其值在给定值 `s` 和 `t` 之间（包含 `s` 和 `t`，要求 `s < t`）的所有元素。若 `s` 或 `t` 不合理，或者顺序表为空，则显示出错信息并退出运行。

### 思路

原思路同样使用变量 `k` 记录向前移动的距离：遍历顺序表，根据当前元素与区间 `[s, t]` 的关系决定是否让后续保留元素前移。

### 代码

```cpp
bool Del_s_t(Seqlist& L, int s, int t)
{

	// k 记录前面已经删除的元素个数，也等于后续保留元素需要前移的距离。
	int k = 0;
	if (L.length == 0 || s >= t)
	{
		return false; // 空表没有元素可删；s >= t 不构成合法区间
	}
	for (int i = 0; i < L.length; i++)
	{
		if (L.data[i]>=s && L.data[i]<=t)
		{
			k++; // 当前元素在闭区间 [s, t] 内，跳过它并让前移距离增加
		}
		else
		{
			// 当前元素需要保留。它前面已经有 k 个元素被删除，
			// 所以把它向左移动 k 个位置，紧凑到已删除元素留下的空位中。
			L.data[i - k] = L.data[i];
		}
	
	}

	L.length -= k; // 删除 k 个元素后更新表长
	return true;
}
```

这里保留了原始代码的判断与移动方式，用来记录“通过 `k` 表示前移距离”的思路。

### 复杂度

只扫描一遍顺序表，时间复杂度为 `O(n)`；空间复杂度为 `O(1)`。

## 05. 有序顺序表去重

### 题目

从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不同。

### 思路

有序表中相同的元素一定相邻。使用快慢指针：`i` 指向最后一个已经确认不重复的元素，`j` 向后扫描；遇到新值时，把新值写到 `i + 1` 的位置。

### 代码

```cpp
bool DeleSame(Seqlist& L)
{
	if (L.length == 0)
	{
		return false; // 空表没有可比较的元素
	}
	int i, j;
	// i 指向最后一个确认不重复的元素，j 向后寻找新的不同值。
	// 有序表中所有相同元素都会相邻，因此只需比较 data[i] 与 data[j]。
	for (i = 0, j = 1; j < L.length; j++)
	{
		if (L.data[i] != L.data[j])
		{
			// 发现新值：先把 i 移到下一个保留位置，再复制新值。
			L.data[++i] = L.data[j];
		}
	}
	L.length = i + 1; // 下标 0 到 i 是去重后保留下来的全部元素
	return true;
}
```

本题“相邻元素才可能重复”的前提来自顺序表本身的有序性。如果表无序，需要先排序或借助额外结构记录出现过的值。

### 复杂度

每个元素最多处理一次，时间复杂度为 `O(n)`；空间复杂度为 `O(1)`。

## 06. 合并两个有序顺序表

### 题目

将两个有序顺序表合并为一个新的有序顺序表，并由函数返回结果顺序表。

### 思路

建立三个指针，分别扫描 `A`、`B` 和结果表 `C`。每次把两表当前较小的元素放入 `C`，某一表遍历完后，将另一表的剩余元素依次追加。

下面的函数用 `bool` 返回是否成功，结果通过输出参数 `C` 带回。调用前需要先初始化 `C`，并保证容量足够。

### 代码

```cpp
bool Merge(Seqlist A, Seqlist B, Seqlist& C)
{
	if (A.length + B.length > C.Maxsize)
	{
		return false; // 结果表容量不足
	}

	// i、j 分别扫描 A、B，k 是结果表 C 的下一个写入位置。
	int i = 0, j = 0, k = 0;

	// 两表都还有元素时，每次把当前较小的元素放入 C。
	while (i < A.length && j < B.length)
	{
		if (A.data[i] < B.data[j])
		{
			C.data[k++] = A.data[i++]; // A 的当前元素较小，先取 A
		}
		else
		{
			C.data[k++] = B.data[j++]; // B 当前元素较小或相等，先取 B
		}
	}

	// 一个表遍历完后，另一个表可能还剩一段连续元素。
	// 由于两个输入表本来就是有序的，直接依次复制即可保持整体有序。
	while (i < A.length)
	{
		C.data[k++] = A.data[i++];
	}
	while (j < B.length)
	{
		C.data[k++] = B.data[j++];
	}

	C.length = k; // C 的长度等于实际写入的元素个数
	return true;
}
```

代码保留了原始归并结构，用两个下标扫描有序表，并把剩下的尾部元素依次追加到结果表。

### 复杂度

时间复杂度为 `O(m+n)`。归并过程本身只使用常数个辅助变量；若把结果表 `C` 计入空间，则需要 `O(m+n)` 个元素空间。

## 07. 交换数组中的两个顺序表

### 题目

一维数组 `A[m+n]` 中依次存放两个线性表 `(a1, a2, ..., am)` 和 `(b1, b2, ..., bn)`。编写一个函数，将数组中两个顺序表的位置互换，使结果变为 `(b1, b2, ..., bn, a1, a2, ..., am)`。

### 思路

使用“三次逆置”：

1. 逆置整个数组，得到 `B^R A^R`；
2. 逆置前 `n` 个元素，恢复 `B` 的顺序；
3. 逆置后 `m` 个元素，恢复 `A` 的顺序。

原思路在同一个数组上完成三次逆置，不创建额外的顺序表。

### 代码

```cpp
typedef int datatype;
int m = 3, n = 4; // 前 m 个元素和后 n 个元素分别构成两个线性表
datatype* A = (datatype*)malloc(sizeof(datatype) * (m + n));

// 逆置数组的闭区间 [left, right]，right 是最后一个元素的下标。
void Reversebetter(datatype A[], int left, int right, int arraysize)
{
	if (left >= right || right > arraysize)
	{
		return; // 区间为空/只有一个元素，或右端点超出约定范围
	}
	int mid = (right + left) / 2; // 区间的中点下标

	// 第 i 次交换一对对称位置：
	// A[left + i] <-> A[right - i]。
	for (int i = 0; i <= mid - left; i++)
	{
		datatype temp = A[left + i];
		A[left + i] = A[right - i];
		A[right - i] = temp;
	}
}

// 通过三次逆置交换数组中的前 m 个元素和后 n 个元素。
void Exchange(datatype A[], int left, int right, int arraysize)
{
	// 设原数组为 A + B，其中 A 有 m 个元素、B 有 n 个元素。
	// 1. 整体逆置后得到 B^R + A^R。
	Reversebetter(A, 0, m + n - 1, arraysize);

	// 2. 逆置前 n 个元素，把 B^R 恢复成 B。
	Reversebetter(A, 0, n - 1,arraysize);

	// 3. 逆置后 m 个元素，把 A^R 恢复成 A。
	// 最终顺序变为 B + A，完成两个线性表的位置交换。
	Reversebetter(A, n, m + n - 1, arraysize);
}
```

这里保留原始的全局变量、函数签名和逆置实现，用三次区间逆置表达交换两个顺序表的思路。

### 复杂度

三次逆置合计处理约 `2(m+n)` 个元素，时间复杂度仍为 `O(m+n)`；空间复杂度为 `O(1)`。
